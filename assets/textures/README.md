# PBR-текстури землі, кори й каміння

Гра малює текстури сама (процедурно). Їх можна замінити справжніми фото-текстурами через
`assets/manifest.json` — без зміни коду.

## Ключі

| Ключ | Де використовується | Що шукати |
|---|---|---|
| `ground_grass` | луки й галявини | трава з землею, лісова галявина |
| `ground_forest` | земля під деревами | лісова підстилка: хвоя, листя, мох |
| `ground_dirt` | стежка, береги | ґрунт, утоптана стежка |
| `ground_rock` | круті схили | скеля, каміння з мохом |
| `bark` | кора ялини, сосни, дуба, сухих дерев і колод (береза має свою) | кора хвойного дерева |
| `rock` | валуни | камінь, скеля |

Для кожного ключа — два файли:

- `albedo` — колір (sRGB);
- `normal` — карта нормалей у форматі **OpenGL** (на Poly Haven — файли з `nor_gl`, на
  ambientCG — `NormalGL`). Формат DirectX (`nor_dx`, `NormalDX`) дасть «вивернуте» освітлення.

## Як підключити

1. Покладіть файли, наприклад, у `assets/textures/ground/` (шляхи — у `manifest.json`).
2. Для потрібного ключа змініть `"enabled": false` на `"enabled": true`.
3. Оновіть сторінку. Якщо файл не завантажився — лишиться процедурна текстура, а пояснення буде
   в консолі браузера.

## Вимоги

- **Безшовні** (tileable) текстури, квадратні: 1024 px (для телефонів), максимум 2048 px.
- JPG або PNG.
- Необов'язково (лише PNG з альфа-каналом): в альфа-каналі `albedo` — висота (height/displacement,
  для природного змішування шарів землі), в альфа-каналі `normal` — шорсткість (roughness).
  Без альфа-каналу гра вважає висоту однаковою, а поверхню — повністю матовою; це теж працює.

## Де взяти легально (CC0 — безкоштовно, без зазначення автора, можна й у комерційному проєкті)

- [ambientCG](https://ambientcg.com) — матеріали Ground, Grass, Rock, Bark, Moss (назви на кшталт `Ground037`).
- [Poly Haven — Textures](https://polyhaven.com/textures) — розділи terrain і rock, кору — пошуком «bark».

Завантажуйте варіант 1K або 2K у JPG і беріть лише карти Color/Diffuse (albedo) і
Normal (GL).
