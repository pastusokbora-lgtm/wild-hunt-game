# Звуки зброї: записи замість синтезу

Усі звуки зброї гра створює кодом (Web Audio) під час запуску — файли не потрібні. Будь-який звук
можна замінити справжнім записом: покладіть файл у цю папку і в `assets/manifest.json`, розділ
`"sounds"`, змініть для нього `"enabled": false` на `true` (шлях — у полі `"url"`).
Поле `"gain"` (необов'язкове) — гучність запису відносно синтезованого звуку (1 — без змін).

## Ключі звуків

| Ключ | Коли звучить |
|---|---|
| `shot_r243`, `shot_r308`, `shot_r338` | Постріл карабіна .243 Win, .308 Win, .338 Win Mag |
| `shot_g12` | Постріл рушниці 12 калібру (куля 12/70) |
| `bolt_up`, `bolt_back`, `bolt_forward`, `bolt_down` | Затвор: рукоятка вгору, назад, уперед, вниз |
| `casing_eject` | Гільза вилітає з вікна |
| `casing_hard`, `casing_soft` | Гільза падає на стежку / на траву й землю |
| `round_in` | Набій входить у магазин |
| `mag_out`, `mag_in` | Відʼємний магазин .308: вийняти, вставити |
| `dry_fire` | Клацання бойка без набою |
| `sg_lever` | Рушниця: ключ відмикання |
| `sg_open`, `sg_close` | Рушниця: переламати стволи, закрити |
| `sg_eject` | Стріляні гільзи рушниці вилітають |
| `shell_in` | Набій входить у патронник рушниці |
| `knife_swing`, `knife_hit` | Ніж: замах, удар |
| `knife_draw`, `weapon_draw` | Дістати ніж / зброю (під час перемикання) |

Звуки затвора, перезаряджання й рушниці відтворюються в ті самі моменти, що й анімація рук і
деталей, тож запис має починатися одразу з потрібного звуку (без тиші на початку).

## Вимоги до записів

- Формат MP3, OGG або WAV (MP3 підтримують усі браузери, зокрема Safari на iPhone).
- Моно або стерео, 44,1 або 48 кГц. Постріли — до 2 с (відлуння додає гра), решта — до 0,5 с.
- Без музики, голосу й сторонніх шумів; нормалізовано до −1 дБ.

## Де взяти легально

- **Freesound.org** — записи з ліцензіями CC0 (можна без зазначення автора) і CC BY (треба вказати
  автора в описі гри). Перевіряйте ліцензію кожного файлу.
- **Sonniss GDC Game Audio Bundle** — щорічні безкоштовні набори професійних звуків для ігор.
- Власні записи (стрільбище, мисливський клуб) — найкращий варіант для правдоподібності.

Якщо файл не завантажився, гра не зупиняється: звучить синтезований звук.
