# Генератор моделей звірів (beast-gen)

Цими скриптами створено моделі сірого вовка, рудої лисиці, зайця-русака й дикого кабана, вбудовані
в гру (`game.js`, розділ 11c, дані — `BEAST_MODEL_DATA`). Для гри вони не потрібні: це «вихідний
код» моделей, щоб їх можна було змінити й перебудувати.

Як працює:
1. **Скульптинг полями відстаней** (`sdf.py`): еліпсоїди, «круглі конуси», трубки з еліптичним
   перерізом, гладке об'єднання й віднімання — на сітці з кроком 1,5–3,5 мм. Анатомія виду — у
   `wolf.py`, `fox.py`, `hare.py`, `boar.py` (кістки, форма, ворс, ваги, забарвлення).
2. **Поверхня** — marching cubes (scikit-image), легкий «ворс» зсувом уздовж нормалей.
3. **Спрощення** — Fast-Quadric-Mesh-Simplification (MIT, github.com/sp4cerat/Fast-Quadric-Mesh-Simplification)
   у сантиметрах і з «лупою» на голові (більше трикутників на морді, очах і вухах). Далекий рівень
   деталізації — спрощення половинними ребрами (латка `fqms-halfedge.patch`, змінна середовища
   `FQMS_HALFEDGE=1`), тож його вершини — підмножина ближнього рівня й обидва ділять один буфер.
4. **Ваги скіну** — найближча кістка (з масками: лівий/правий бік, щелепа, хвіст) і дифузія по сітці.
5. **Забарвлення** — візерунок виду в кольорах вершин, затінення западин за полем відстаней,
   шорсткість (ніс, очі, кігті, ратиці) — в альфа-каналі.
6. **Пакування** у формат WHD1 (той самий, що в оленів): квантовані позиції, октаедричні нормалі,
   кольори, кістки й ваги, індекси двох рівнів деталізації (дельта-varint), base64.

Залежності: Python 3, numpy, scipy, scikit-image; компілятор C++ для спрощувача:

    git clone https://github.com/sp4cerat/Fast-Quadric-Mesh-Simplification fqms
    cd fqms && git apply ../fqms-halfedge.patch
    g++ -O2 -include cstdint -o simplify src.cmd/Main.cpp

Запуск (з цієї теки):

    FQMS=/шлях/до/fqms/simplify python3 run.py wolf,fox,hare,boar
    python3 emit_js.py out/07d-beast-data.js

Отриманий `07d-beast-data.js` замінює блок `BEAST_MODEL_DATA` у `game.js`.
